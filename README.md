The Smart Dustbin using Arduino is an automated waste management system designed to enhance cleanliness and hygiene using sensor-based technology. This system uses an ultrasonic sensor to detect human presence and automatically opens the dustbin lid when someone approaches. It is controlled by an Arduino microcontroller, which processes sensor inputs and controls a servo motor to operate the lid. In more advanced versions, the system can also detect fill levels and send alerts when the bin is full. This project promotes hands-free waste disposal, reducing the spread of germs and encouraging better hygiene in both public and private spaces.
